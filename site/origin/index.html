Neuradix Origin

One origin.
Every discipline.

Origin is a local-first, cross-platform parametric engineering platform being designed so mechanical, architectural, civil, electrical, plant and other engineering views can share stable identity and engineering meaning.

Architecture validationWindows · macOS · LinuxRust + Flutter
Origin is not yet presented as production CAD. The current implementation validates the architectural boundaries needed for a broader engineering platform.

Semantic before geometric.

An engineering object should not become unrelated copies simply because different disciplines need different representations. Origin's direction is to share identity, parameters, documents, revisions and outputs while allowing each discipline to retain its own modelling rules.

Local-first projects

Projects are intended to remain usable without a mandatory cloud service, with versioned and recoverable project data.

Cross-platform core

A Rust engineering engine owns the authoritative model while Flutter provides the desktop interaction layer across Windows, macOS and Linux.

Replaceable infrastructure

Geometry kernels, renderers, importers and solvers are kept behind stable internal contracts instead of becoming inseparable from the document model.

Multi-discipline direction

The long-term family includes Mechanical, Architecture, Civil, Electrical, Plant, Woodworking, Simulation and production-engineering capabilities. Shop-floor execution belongs in the separate Neuradix Manufacturing product.

Inside the current build.

These are not concept renders. They are deterministic scenes from Origin's committed UI regression suite, so the product imagery can evolve with the application instead of drifting away from it.

Parameters stay visible

Engineering intent remains inspectable alongside the model instead of being reduced to disconnected geometry.

Constraint-aware sketching

Dimensioned sketch interaction is part of the real desktop surface and is regression-tested visually.

Product imagery is generated from the real Origin application UI.

Origin is being built from the engineering model outward.
